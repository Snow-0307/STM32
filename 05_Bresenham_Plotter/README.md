# STM32 写字机通用绘图系统（Bresenham + 指令队列）

## 项目概述
对上一版写字机代码进行架构重构，实现Bresenham直线插补、二进制串口协议、环形指令队列。
底层绘图API已抽象为空跑/画点/画线三种操作，为后续G-code解析和图形界面打下基础。

硬件结构参考大鱼DIY写字机v2.2开源方案。

## 功能
- **十六进制串口协议**：帧结构 `AA + Mode + X_H + X_L + Y_H + Y_L + BB`，7字节一帧
- **三种绘图模式**：
  | 模式 | 功能 | 动作描述 |
  |------|------|----------|
  | 01 | 空跑移动 | 移动到坐标，不落笔 |
  | 02 | 画点 | 移动到坐标，落笔点一个点，抬笔 |
  | 03 | 画线 | 落笔，移动到坐标，抬笔 |
- **环形指令队列**：最多缓存16条指令，主循环按序取出执行
- **Bresenham直线插补**：任意角度斜线平滑绘制，支持8个方向（含水平垂直和对角线）

## 架构说明
- 串口接收中断 → 协议解析状态机 → 指令入队
- 主循环状态机 → 取指令 → Bresenham插补 → 电机执行
- 三路定时器独立PWM驱动XYZ轴，互不干扰
- `function.c` 封装所有底层动作：`set_motor_dir`、`motor_step`、`pen_down`、`pen_up`、`bresenham_init`、`bresenham_step`

## 涉及知识
- Bresenham直线插补算法
- 串口二进制协议设计（帧头帧尾 + 解析状态机）
- 环形缓冲区 / 指令队列
- 多电机协同插补
- 前后台系统架构

## 硬件
- 主控：NUCLEO-G070RB
- 结构：大鱼DIY写字机v2.2
- 电机：三个步进电机 + 驱动模块

## 快速开始
用 Keil v5 打开 `src/` 目录下的 `.uvprojx` 文件，编译后烧录到 NUCLEO-G070RB。

串口协议示例（十六进制）：
`AA 01 00 32 00 64 BB` → 空跑移动到 (50, 100)
`AA 02 00 32 00 64 BB` → 在 (50, 100) 画点
`AA 03 00 32 00 64 BB` → 从当前画线到 (50, 100)
