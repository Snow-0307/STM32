# STM32 状态机控制步进电机多档转速

## 功能
- 一个按钮（B1）控制步进电机在“低速→中速→高速”三个状态间循环切换
- 状态切换瞬间完成，无 `HAL_Delay` 阻塞延时
- 电机转速由脉冲频率控制，各档位速度稳定

## 解决什么问题
传统按键控制电机常用延时消抖或阻塞等待，导致按键响应迟钝、其他任务卡死。
本方案用 **状态机** 管理电机档位，脉冲输出在定时器中断中自动运行，按键响应与电机控制互不干扰。

## 涉及知识
- 状态机设计（状态枚举、状态切换）
- 定时器输出比较（脉冲频率调节）
- GPIO 按键输入（外部中断触发）
- 步进电机驱动（脉冲+方向控制）

## 硬件
- NUCLEO-G070RB
- 步进电机
- 步进电机驱动模块（A4988)
