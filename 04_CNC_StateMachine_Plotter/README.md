# STM32 三轴写字机控制系统（状态机版）

## 项目来源
硬件结构参考大鱼DIY写字机v2.2开源方案，软件部分用STM32G070从零编写。

## 功能
- **串口指令控制**：发送 w/a/s/d 控制XY轴空跑指定距离，发送 r 抬笔归位
- **按键自动绘图**：按下按钮B1，自动完成落笔→画正方形→抬笔→归位的全流程
- **多电机协同**：三路独立定时器PWM驱动XYZ三个步进电机，互不干扰
- **非阻塞运行**：全程状态机驱动，无Delay，各任务可并发

## 控制逻辑
### 状态机流转
IDLE → START → PEN_DOWN → DRAW_DOWN → DRAW_LEFT → DRAW_UP → DRAW_RIGHT → PEN_UP → DONE → IDLE

### 串口指令表
| 指令 | 功能 | 方向控制 |
|------|------|----------|
| w | Y轴正方向空跑 | PB4高 PA8低 |
| a | X轴负方向空跑 | PB4低 PA8低 |
| s | Y轴负方向空跑 | PB4低 PA8高 |
| d | X轴正方向空跑 | PB4高 PA8高 |
| r | 抬笔Z轴归位 | PA9高 |
| 按键B1 | 自动画正方形 | 先落笔后画图 |

## 涉及知识
- 多电机协同控制（TIM1/TIM15/TIM3独立PWM）
- 状态机架构（12状态管理完整流程）
- 串口指令解析（非阻塞中断接收）
- 步进电机方向控制（GPIO电平组合）
- 增量式运动控制（定时器中断计步）
- 位移量换算（毫米转步数宏定义）

## 硬件
- 主控：NUCLEO-G070RB
- 结构：大鱼DIY写字机v2.2
- 电机：三个步进电机 + 驱动模块
