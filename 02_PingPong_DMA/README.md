# STM32 DMA 乒乓缓冲串口通信

## 功能
- 开启 USART2 DMA 接收，使用两个 10 字节缓冲区（RxBuffer_A / RxBuffer_B）交替接收
- 任一缓冲区收满后：LED 闪烁 20 次（100ms周期），同时串口回传该缓冲区名称（`full_A` / `full_B`）
- **CPU 零阻塞**：DMA 在后台自动搬运数据，主循环继续处理 LED 状态机和回显任务

## 解决什么问题
传统中断接收每收到1个字节就中断CPU一次，频繁打断主循环。本方案用 **DMA + 乒乓缓冲**，CPU只在缓冲区满（10字节）时被通知一次，极大降低中断频率，确保多任务流畅运行。

## 涉及知识
- DMA 外设配置（USART2_RX + USART2_TX，正常模式，从外设到内存 / 从内存到外设）
- 乒乓双缓冲机制（缓冲区自动切换，硬件级数据搬运不丢包）
- 前后台任务协同（DMA 中断回调设标志位，主循环非阻塞回显与 LED 闪烁）

## 硬件
NUCLEO-G070RB （板载LED LD4 接 PA5，ST-Link虚拟串口 USART2）
